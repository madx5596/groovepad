# GroovePad - Flutter Audio Loop Player

Музыкальное приложение для Android, позволяющее воспроизводить и управлять аудиосемплами в виде сетки из 16 ячеек.

## Функции

- 🎵 **16 ячеек для семплов** - загружайте и воспроизводите аудиофайлы
- 📁 **Загрузка собственных файлов** - поддержка MP3, WAV, OGG и других аудиоформатов
- ▶️ **Легкое управление** - коснитесь для воспроизведения, долгий тап для удаления
- 🎚️ **Контроль воспроизведения** - кнопки для остановки и очистки всех семплов
- 🎨 **Современный интерфейс** - тёмная тема с визуальными эффектами

## Установка

### Требования
- Flutter SDK (версия 2.19.0+)
- Android SDK
- Visual Studio Code с расширением Flutter

### Инструкции

1. Клонируйте репозиторий:
```bash
git clone https://github.com/madx5596/groovepad.git
cd groovepad
```

2. Установите зависимости:
```bash
flutter pub get
```

3. Подключите устройство Android или запустите эмулятор

4. Соберите APK:
```bash
flutter build apk --release
```

Или для отладки:
```bash
flutter run
```

## Использование

1. **Загрузка семпла**: Коснитесь пустой ячейки и выберите аудиофайл
2. **Воспроизведение**: Коснитесь ячейки с семплом для воспроизведения
3. **Удаление**: Долгий тап по ячейке для удаления семпла
4. **Остановка**: Нажмите кнопку "Стоп" для остановки текущего воспроизведения
5. **Очистка**: Нажмите "Очистить всё" для удаления всех семплов

## Зависимости

- **audioplayers** - воспроизведение аудио
- **file_picker** - выбор файлов из хранилища
- **permission_handler** - управление разрешениями
- **provider** - управление состоянием
